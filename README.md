# Portal de Segurança e Saúde no Trabalho — Patrícia Pontes de Oliveira Lima

Portal público de conteúdo educativo sobre Segurança e Saúde no Trabalho (SST), prevenção, Normas Regulamentadoras, GRO/PGR, EPI/EPC, ergonomia e saúde ocupacional.

## Site
https://andreluisplima.github.io/seguranca-do-trabalho-patricia/

## Recursos
- Layout responsivo
- Menu mobile
- Pesquisa e categorias de artigos
- Biblioteca NR 01–38 com indicação das NRs revogadas
- Links para fontes oficiais do Ministério do Trabalho e Emprego
- Área de legislação
- Downloads de modelos educativos
- Formulário de contato via cliente de e-mail
- Atalho preparado para WhatsApp
- SEO básico, canonical, Open Graph e Schema.org

## Aviso
Conteúdo educativo e informativo. Para aplicação profissional, consulte sempre a legislação oficial vigente e profissionais legalmente habilitados quando aplicável.
